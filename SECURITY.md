# Security Policy

The HUPA team and community take the security of our application and user data seriously.

---

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within HUPA:

1. **Do not create a public GitHub issue**.
2. Report the vulnerability privately via **GitHub Security Advisories** on the repository or email the maintainers directly.
3. Please include:
   - A detailed description of the vulnerability
   - Step-by-step reproduction instructions or a proof-of-concept
   - Impact assessment on client state, authentication sessions, or database records

### Response Timeline
- **Acknowledgement**: Within 48 hours
- **Assessment and Fix**: Within 7 business days for critical vulnerabilities
- **Public Disclosure**: Coordinated after a fix has been released
